# Projeto_IV_Monitoramento_de_Abelhas_Fatec_2026

Este projeto visa desenvolver uma aplicação e novidade tecnológica monitorando a saúde de abelhas nativas sem ferrão de forma menos invasiva buscando preservar a espécie e o ecosistema. Este monitoramento será realizado com ajude de IoT's e recursos de Inteligência Artivicial e Visão computacional acoplados as colmeias
